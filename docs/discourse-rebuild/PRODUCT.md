# 产品定义

## 一句话定位

智工 BBS 是一个面向智能工程学院师生的、邀请制、半匿名、以主题讨论和校园信息沉淀为核心的现代社区。

## 核心用户流程

1. 用户使用邮箱、用户名、密码和邀请码创建账号。
2. 用户从最新、热门、分类或搜索进入主题。
3. 用户发布 Markdown 图文主题，或在已有主题中回复。
4. 主题留言采用固定两层结构；回复楼中楼时，新回复留在对应一级留言下，并标明回复对象。
5. 用户通过点赞、收藏、通知和举报参与社区互动与治理。
6. 用户在个人主页查看自己发布、回复和收藏的内容。

## 初始分类

- 日常吐槽：校园日常和轻量讨论。
- 学习交流：知识、技术、科研和经验分享。
- 打听求助：面向院内成员的问题与互助。
- 恋爱交友：同学关系和兴趣交流。
- 课程专区：课程相关讨论与资料沉淀。
- 其他：暂时无法归入上述分类的内容。

## 非目标

- 二手交易市场。
- 教师或课程打分平台。
- 简历投递与招聘系统。
- 用户积分排行榜。
- 学校统一身份认证或通用 OAuth2 平台。
- Reddit 式无限嵌套评论。
- 对 Discourse 核心源码的长期 fork。

## 产品与实现边界

邀请制、半匿名、学院内部、主题讨论、内容沉淀和固定两层留言是产品要求。旧项目的 Vue 2、Go、MySQL 与单标签属于旧实现约束，不继续作为新架构要求。固定两层留言由 Discourse 原生 Nested Replies 实现，不恢复旧评论后端。
