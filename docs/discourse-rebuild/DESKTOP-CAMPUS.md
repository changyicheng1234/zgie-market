# 桌面校园主题

分支：`codex/meta-desktop-campus`，基于移动端阶段的 `8467bcf`。原移动端分支未修改。

## 视觉与导航

- 768px 及以上使用工科蓝（主按钮 `#005A9C`），搭配浅蓝渐变或深灰蓝背景；跟随原生深浅色偏好。
- 页眉提供原生配色选择按钮，可选浅色、深色或自动，选择由 Discourse 在当前浏览器保存。首页使用低饱和淡蓝亮色、淡紫暗色，深色帖子卡片仍为 `#1a1a1a`。部署现有站点可单独设置 `SiteSetting.interface_color_selector = "header"`，无需重新应用全部站点配置。
- 桌面主导航按“首页、帖子、我的帖子、我的消息”排列，其下才是分类。“校园集市”默认展开，显示当前用户可见的实习推荐、考研保研分享、二手交易、课程经验分享、日常吐槽。用户仍可手动折叠。
- 桌面横幅仅展示前三个可见校园分类（默认实习推荐、考研保研分享、二手交易），三列加大卡片，最小高度 112px；完整五类保留在左栏。原生 General / Site Feedback 分类快捷栏仅在桌面隐藏。不会删除分类、移动帖子或改变权限。
- 独立首页使用原生 `/custom` 扩展点；桌面访问根路径或点击站点标志进入首页。首页读取最多 20 条原生最新帖子快照，不加载更多或订阅实时列表更新；底部“显示全部”进入 `/latest`。
- “帖子”(`/latest`)、热门和分类列表保留原生分页/滚动行为，不显示首页横幅与右侧热榜。
- 热榜只在首页显示。1200px 及以上采用同一 CSS Grid，与信息流卡片顶部严格对齐；较窄桌面自然堆叠，手机不显示。
- 首页信息流和热榜共用 16px 圆角，深色模式卡片及已读/未读帖子行均为 `#1a1a1a`，浅色模式沿用原生浅色背景。
- 热榜按 Meta Branded 参考图采用独立圆角卡片、“热门帖子”火焰图标标题栏、通栏分隔线、帖子标题、彩色分类标签和活动时间；不显示排名序号。底部“显示全部”进入原生 `/hot`。宽屏时卡片约占内容区的三分之一。
- 767px 及以下保留原有紫色移动主题、横幅及四项底栏。分类属于数据库共享内容，分类改名或新增会对所有客户端生效；移动端代码和布局不变。

## 分类初始化

部署本分支后，在 Discourse 容器中运行：

```sh
bin/rake zgie_bbs:configure_campus_categories
```

该任务只创建缺少的校园分类，并将仍使用默认名称“课程专区”的 `courses` 分类改为“课程经验分享”。保留已有 ID、帖子、权限和自定义名称，可重复执行，不覆盖登录和邀请设置。三个新增分类 slug 为 `internships`、`postgraduate`、`second-hand`，原有 `courses`、`daily` 继续使用。

## 热榜

`GET /zgie-bbs/hot-topics.json` 在当前用户有权访问的校园分类中按 Discourse 的 `topic_hot_scores.score` 降序排序，然后取 5 篇。同分或尚未产生热度分数时，按最近活动和 ID 排序。不会为了凑数创建帖子；不足 5 篇时显示实际数量。

沿用 TopicQuery 的权限与普通话题过滤，排除私信、已删除/未列出的话题和分类介绍；登录制站点要求登录。前端使用文本绑定显示标题，提供加载、空列表和失败重试状态。

关闭 `zgie_bbs_branded_layout` 会同时关闭桌面配色、校园导航和热榜，恢复原生类别侧栏；分类数据保留。
